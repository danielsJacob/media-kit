# media-kit
![Description](media-kit.png)

A media toolkit built in Rust for common video processing tasks

## Getting Started

```bash
cargo run --release
```


## Tools

- Compressor - compress video
- Converter - convert video format
- Downloader - download video from url source
- Extractor - extract media
- Probe - inspect media
- Reformatter - reformat video
- Remux - change container
- Subtitles - extract/burn subtitles
- Thumbnail - generate thumbnail
